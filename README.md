# TOUR-DNA

지역 관광 데이터를 진단하고, 관광 문제 해결 전략부터 실행 가능한 관광상품까지 설계하는 B2B 관광 의사결정 플랫폼입니다.

TOUR-DNA는 여행자의 취향에 맞는 장소를 단순히 나열하는 서비스가 아닙니다. 지자체·관광재단, 여행사·DMC,
축제 기획자가 지역의 관광 현황을 근거와 함께 확인하고, 목표에 맞는 전략을 비교한 뒤, 사람이 코스를 다듬고
실행 가능성을 점검하도록 돕습니다.

- 운영 서비스: [tour-dna.lib.lc](https://tour-dna.lib.lc)
- 저장소: [herb39/TOUR-DNA](https://github.com/herb39/TOUR-DNA)

## 이 서비스가 해결하는 문제

관광상품을 만들 때는 “어디가 유명한가”만으로는 충분하지 않습니다.

- 지역의 관광 강점과 취약점이 무엇인지
- 체류·소비·비수기·분산 중 무엇을 먼저 해결해야 하는지
- 선택한 전략이 실제 지역 자원과 맞는지
- 코스가 이동·운영·식사·숙박 측면에서 실행 가능한지
- 결과를 어떤 KPI로 확인할지

를 함께 판단해야 합니다. TOUR-DNA는 이 판단을 `지역 진단 → 기회 발견 → 전략 비교 → 코스 편집 → 품질 검증 →
실행안 확정` 흐름으로 연결합니다.

## 주요 사용자

| 사용자 | 지원하는 결정 |
|---|---|
| 지자체·관광재단 | 지역 관광 문제의 우선순위, 자원 활용 방향, 정책 성과와 협력 과제 |
| 여행사·DMC | 판매 가능한 상품 콘셉트, 타깃별 코스, 체류·소비 연결과 운영 위험 |
| 축제 기획자 | 축제 방문객의 주변 관광·식음·숙박 연계와 현장 운영 검토 |

## 핵심 서비스 흐름

1. 지역과 여행 시기, 역할, 기간을 입력합니다.
2. 해결하고 싶은 관광 문제와 목표를 선택합니다.
3. 콘텐츠 테마와 여행 조건을 분리해 선택합니다.
4. TOUR-DNA 5축으로 지역을 진단합니다.
5. 관광사업 기회와 전략 3안을 비교합니다.
6. 선택한 전략의 실행안을 엽니다.
7. 자동 초안을 확인하고 추천 후보를 추가하거나 일정 순서를 편집합니다.
8. 지도와 실시간 품질검증 패널로 코스를 점검합니다.
9. KPI·위험·홍보자료를 정리하고 저장·인쇄합니다.

축제·이벤트 연계가 필요한 경우 분석 화면에서 해당 지역·월의 공식 축제 후보를 확인하고 Anchor를 확정할 수
있습니다. 현재 Anchor의 서버 저장·변경·삭제까지 구현되어 있으며, 기존 코스에 자동 고정하거나 전후 관광·식음·
숙박을 자동 연결하는 기능은 다음 단계입니다.

## TOUR-DNA 5축

5축 점수는 절대적인 관광 등급이 아니라 같은 비교지역 안에서 상대적인 위치를 이해하기 위한 지수입니다.

| 축 | 의미 |
|---|---|
| 수요 | 지역 관광 서비스와 방문 수요가 어느 정도 형성되어 있는지 |
| 체류 | 1박 이상 체류와 체류형 관광 기반이 어느 정도인지 |
| 소비 | 외지인 소비와 지역 내 소비 연결 가능성을 판단하는 신호 |
| 다양성 | 방문객 연령·국적·소비 구성의 다양성 |
| 연계 | 중심 관광지와 음식·숙박·체험 자원이 함께 상품화될 수 있는 구조 |

화면의 `DNA 상대지수`는 비교지역 기준의 사용자 표시값입니다. 개별 `근거 보기`에 나오는 원값·정규화값은
특정 지표의 값이므로 축 최종 지수와 동일하지 않습니다. 데이터 기준월과 출처 구성도 화면에서 함께 확인할 수
있습니다. 산정 방식은 [점수 산정 모델](docs/scoring-model.md)을 참고하세요.

## 기획 입력

### 콘텐츠 테마 8종

콘텐츠 테마는 코스가 어떤 관광 경험을 제공할지 정하는 축입니다.

- 미식: 음식·시장·로컬푸드
- 자연: 산·바다·생태·자연경관
- 웰니스: 온천·숲·힐링·휴식
- 문화·역사: 유적·박물관·전통문화
- 문화예술: 공연·전시·미술·문화공간
- 레저·액티비티: 스포츠·체험·야외활동
- K-콘텐츠: 촬영지·한류·콘텐츠 명소
- 야간관광: 야경·야시장·야간공연

### 여행 조건 4종

여행 조건은 콘텐츠 테마와 별도로 적용하는 이동·동행 제약입니다.

- 반려동물 동반
- 무장애·이동약자
- 뚜벅이·대중교통
- 가족·유아동

테마와 조건을 분리하면 `문화예술 × 무장애`, `자연 × 반려동물`, `K-콘텐츠 × 뚜벅이`처럼 조합할 수 있습니다.
현재 조건은 입력·저장·표시와 일부 코스 판단에 연결되어 있으며, 모든 POI·숙박·식음 시설의 접근성·반려동물
가능 여부를 실제 근거로 검증하는 범위는 계속 확대 중입니다.

### 관광 문제 목표

체류 확대, 지역 소비 확대, 방문객 증가, 재방문 유도, 비수기 활성화, 관광객 분산, 지역 소상공인 매출 연계,
지역 브랜드 이미지 제고, 신규 타깃 시장 개척 중 주 목표와 보조 목표를 선택할 수 있습니다. 목표는 전략 문구와
KPI를 선택할 때 함께 사용됩니다.

## 주요 기능

### 지역 진단

지역의 DNA 5축, 핵심 관광 지표, 데이터 기준월, 출처 구성, 강점과 개선 기회를 한 화면에서 확인합니다.
유사지역 비교와 벤치마킹 포인트도 제공하지만, 비교 우위가 확인되지 않으면 억지로 사례를 만들지 않습니다.

### 기회·전략 제안

관광사업 기회 3안과 전략 3안을 보여줍니다. 전략 카드는 해결하려는 문제, 활용 자원, 체류 방식, 실행 난이도,
기대 효과, 위험을 비교할 수 있고, 역할별 적합도와 1순위 추천 근거를 확인할 수 있습니다.

### 코스 스튜디오

- 선택 전략에 맞춘 자동 코스 초안
- 별도 패널의 추천 후보 풀
- 후보를 날짜에 추가하거나 일정으로 Drag & Drop
- 일정 항목의 순서·시간·체류시간·일차 변경
- PC 화면의 날짜별 가로 배치
- 일정 변경에 따른 지도 마커·동선 갱신
- 동일 시설·입점 매장 중복 억제와 테마 적합도 표시

추천 후보는 자동 코스에 무조건 포함되는 목록이 아닙니다. 대표 후보와 보조 후보를 구분해 보여주며, 기획자가
직접 확인한 장소만 일정에 넣을 수 있습니다.

### 실시간 품질검증

코스 편집 후 테마 적합도, 이동 현실성, 동일 시설 중복, 식사·숙박 구성, 운영시간·휴무일, 실행 가능성,
데이터 신뢰도를 다시 점검합니다. 경고는 실패 확정이 아니라 추가 확인이 필요한 신호일 수 있으며, 데이터가
부족한 경우 `확인 필요`로 구분합니다.

### 축제·이벤트 Anchor

입력한 지역·연도·월에 대해 한국관광공사 `searchFestival2`의 공식 행사 기간과 지역 코드가 일치하는 후보를
탐색합니다. 사용자는 후보를 고르고 연계 날짜·여행 일차·시간 조건을 직접 확인한 뒤 프로젝트 Anchor로 확정할 수
있습니다.

- 행사 기간·지역·주소·출처를 확인
- 여행월과 겹치는 날짜 중 계획 날짜를 직접 선택
- 여행 일차와 시간 블록을 직접 지정
- 공식 시각이 없으면 `공식 시각 미확정`으로 저장
- 확정 Anchor를 변경하거나 삭제

공식 데이터가 없을 때 행사를 추정하지 않습니다. 현재 단계에서는 Anchor 확정이 코스에 자동 삽입되지 않으며,
축제 전후 장소 연결은 후속 기능입니다. Production DB에 Anchor migration이 적용되지 않은 환경에서는 후보 확인만
가능하고 확정 저장은 보류될 수 있습니다.

### 실행안·홍보·보고

선택 전략을 실행안으로 만들면 코스, 상품 기획 요약, 운영 체크리스트, 위험과 대응안, KPI, 메모를 편집하고
저장할 수 있습니다. 홍보자료는 제안서 요약, 랜딩, Instagram, 블로그, 카드뉴스, 숏폼, 역할별 콘텐츠 형식으로
생성·편집할 수 있으며, 인쇄 화면에서 분석·전략·코스·홍보자료를 PDF로 출력할 수 있습니다.

## 사용자 매뉴얼

### 1. 새 프로젝트 만들기

1. 홈에서 `새 관광상품 기획`을 선택합니다.
2. 프로젝트명, 역할, 시·도·시·군·구, 여행 연도·월을 입력합니다.
3. 내·외국인, 연령대, 동행 유형을 선택합니다.
4. 주 목표와 보조 목표, 여행 기간, 예산, 이동 수단, 그룹 규모를 입력합니다.
5. 콘텐츠 테마와 여행 조건을 각각 선택합니다.
6. 필요하면 제외 테마와 메모를 입력합니다.
7. `분석 시작`을 선택합니다.

프로젝트 비밀번호를 입력하면 비밀번호를 아는 사람만 해당 프로젝트를 열 수 있습니다. 계정 기반 소유권은
제공하지 않으므로 공유 범위를 확인한 뒤 사용하세요.

### 2. 분석 결과 읽기

1. 상단의 강점·개선 축과 `DNA 상대지수`를 먼저 확인합니다.
2. 분석 기준월과 데이터 상태를 확인합니다.
3. `근거 보기`를 열어 개별 지표의 원값·정규화값·출처를 확인합니다.
4. `입력 조건 보기`에서 분석에 사용된 타깃·목표·테마·여행 조건을 다시 확인합니다.
5. 관광사업 기회와 유사지역 비교를 읽고, 우리 지역의 문제와 활용 가능한 자원을 좁힙니다.
6. 전략 3안 비교에서 역할 적합도, 해결 문제, 활용 자원, 기대 효과, 실행 난이도를 비교합니다.
7. 검토할 전략의 `이 전략 선택`을 누릅니다.

숫자 하나만으로 전략을 확정하지 말고, 데이터 출처·기준월·현장 조건과 함께 해석하세요.

### 3. 축제 Anchor 확정하기

1. 분석 화면의 `축제·이벤트 연계 후보`에서 후보를 확인합니다.
2. 공식 행사 기간과 지역이 기획 지역·여행월에 맞는지 확인합니다.
3. 연계할 후보를 선택합니다.
4. 행사 기간과 여행월이 겹치는 계획 날짜를 직접 지정합니다.
5. 여행 몇 일차에 둘지 지정합니다.
6. 공식 행사 시각이 있으면 조건을 확인하고, 없으면 미확정 또는 기획 시간대를 선택합니다.
7. `이 조건으로 Anchor 확정`을 선택합니다.

후보를 선택한 것과 서버에 확정 저장한 것은 다릅니다. 날짜·일차·시간 조건을 확인하고 확정 저장해야 다른
브라우저에서도 프로젝트 Anchor를 확인할 수 있습니다.

### 4. 코스 스튜디오 사용하기

1. 분석 화면에서 선택한 전략의 실행안을 엽니다.
2. 자동 생성된 코스를 먼저 훑어보고, 장소보다 전체 동선과 체류 흐름을 확인합니다.
3. 오른쪽 `추천 후보` 패널을 열어 대표 후보·보조 후보·적합도 근거를 확인합니다.
4. 후보 카드에서 날짜를 고른 뒤 `이 날짜에 추가`를 누르거나 후보를 일정으로 끌어옵니다.
5. 일정 항목을 Drag & Drop으로 순서 또는 날짜를 바꿉니다. 필요하면 위·아래 버튼과 날짜 선택도 사용할 수
   있습니다.
6. 각 항목의 시간과 체류시간을 실제 운영 계획에 맞게 수정합니다.
7. 지도에서 마커와 동선을 확인합니다.
8. `코스 품질 점검`의 확인 필요 항목을 열어 장거리 이동, 중복, 식사·숙박, 운영시간, 테마 적합도를 확인합니다.
9. 체크리스트·위험과 대응안·KPI·메모를 정리하고 `저장`을 누릅니다.

PC에서는 날짜별 열을 함께 보며 편집할 수 있고, 키보드 사용자는 항목별 위·아래·날짜 이동 버튼을 사용할 수
있습니다. 코스는 자동 완성본이 아니라 기획자가 현장성과 운영 조건을 반영해 확정하는 초안입니다.

### 5. 홍보자료와 인쇄물 만들기

1. 실행안 화면에서 홍보자료 편집 영역을 엽니다.
2. 필요한 채널의 문구를 확인하고 수정합니다.
3. 미리보기에서 제안서·랜딩·Instagram·블로그·카드뉴스·숏폼 형식을 확인합니다.
4. 실행안의 `인쇄/PDF 보기`를 선택합니다.
5. 분석 기준월, 전략, 코스, KPI와 홍보자료를 확인한 뒤 브라우저 인쇄 기능으로 저장합니다.

## 데이터 출처와 신뢰성

TOUR-DNA는 한국관광공사 공공데이터를 중심으로 지역 관광 수요·체류·소비·다양성·관광자원·방문자 정보를
구성합니다.

| 데이터 | 사용하는 이유 |
|---|---|
| `TAR_SVC_DEM` | 체류·소비 관련 관광 수요 신호 |
| `TOU_RES_DEM` | 관광 서비스·자원 수요 신호 |
| `TOU_DIV_IX` | 관광객 구성의 다양성 |
| `VISITOR_CNT` | 외지인·외국인 방문자 수와 증감 흐름 |
| `TOUR_INFO` | 관광지·음식·숙박·체험 POI와 공식 분류 |
| `searchFestival2` | 여행월과 지역이 맞는 공식 축제·행사 기간 |
| Kakao Map·Mobility | 지도 표시와 전용차량 이동거리·시간 보완 |

서비스는 다음 원칙을 지킵니다.

- 없는 수치나 장소를 임의로 만들지 않습니다.
- 분석 기준월과 데이터 출처를 표시합니다.
- 검증된 `ACTIVE Dataset`을 기준으로 분석합니다.
- 데이터가 부족하면 `MISSING`, 추정, 확인 필요를 구분합니다.
- 공식 일정이 없는 축제를 현재 행사로 추정하지 않습니다.
- 지도 API나 실제 경로가 없으면 목록·좌표·추정 경로로 표시할 수 있습니다.

## 서비스 이용 시 주의사항

- 추천 결과는 관광상품 기획을 돕는 의사결정 자료이며, 최종 확정 전에 현장 답사와 운영자 확인이 필요합니다.
- 운영시간·휴무일·시설 이용 가능 여부는 변경될 수 있습니다.
- 무장애·반려동물 조건은 모든 시설의 실제 근거가 연결된 상태가 아니므로 `확인 필요`를 우선합니다.
- 이동시간은 이동 수단과 경로 데이터 상태에 따라 달라질 수 있습니다.
- 축제 일정은 공식 데이터에 포함된 기간을 기준으로 하며, 정확한 행사 시각이 없으면 미확정으로 남습니다.
- Production에 새 DB migration이 적용되지 않은 경우 해당 기능은 배포 상태에 따라 제한될 수 있습니다.
- AI 또는 규칙으로 만들어진 문구는 실무자가 검토·수정한 뒤 외부에 사용해야 합니다.

## 현재 제품 범위와 다음 우선순위

현재 제품은 `지역 문제 진단 → 전략 비교 → 자동 초안 → 사람 편집 → 실시간 검증 → 실행안 확정` 흐름을 사용할
수 있는 상태입니다. 콘텐츠 테마 8종, 추천 후보 풀, Drag & Drop, 지도 갱신, 실시간 코스 품질검증, 홍보자료와
인쇄 기능이 연결되어 있습니다.

다음 우선순위는 다음과 같습니다.

1. 확정한 축제 Anchor를 사용자가 승인한 일정에 고정하고 전후 관광·식음·숙박 후보를 연결합니다.
2. 전략의 핵심 테마가 자동 초안과 후보 재정렬에 일정 비중으로 반영되도록 강화합니다.
3. 무장애·반려동물 조건을 실제 POI·숙박·식음 근거와 연결하고, POI 유형별 체류시간·이동거리 검증을 고도화합니다.

운영자 화면은 현재 제품 범위에 포함하지 않습니다. POI 품질 보정은 사용자 흐름을 방해하지 않는 내부 추천·검증
계층으로 관리합니다.
